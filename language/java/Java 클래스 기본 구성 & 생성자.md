## 1. 클래스 기본 구성


### 1.1 클래스란?

클래스는 객체를 만들 수 있는 설계도이다. 여기선 클래스, 객체, 인스턴스 이 3개의 개념이 중요한데, 조금 헷갈릴 수도 있다.

- **클래스**
    
    객체를 만들어낼 수 있는 ‘설계도’이고 이 클래스를 이용해서 만드는 객체를 인스턴스라고 부른다.
    
- **객체**
    
    ‘설계도’를 이용해서 만들어낸 데이터이다.
    
    - 여기서 ‘JS에서 클래스 없이 객체 잘 만들어서 썼고 Java라고 다를 것 같진 않은데 그럼 틀린 개념 설명 아닌가?’ 라고 생각을 했다
        
        그런데 사실 알고 보니까 JS랑 Java랑 클래스 문법만 보기에 비슷한 거지 내부적으로 구현되는 방식 자체가 달라서 Java에서는 객체를 선언해서 써도 내부적으로는 클래스를 이용해서 생성된다고 한다.
        
- **인스턴스**
    
    ‘이 객체가 어떤 설계도로 부터 만들어졌는가’라는 관계를 말할 때 사용된다.
    
    쉬운 에시로 설명을 하자면 아래 코드에서 ‘cat은 Animal의 인스턴스다’ 라고 말할 수 있다.
    
    ```java
    Animal cat = new Animal();
    ```
    

### 1.2 필드

필드는 클래스 안에서 선언된 변수를 말하는데, 선언 위치와 선언자에 따라서 3가지 종류로 나뉜다.

- 클래스 변수
    
    클래스 변수는 `static`  키워드를 가지는 변수로 클래스 내에서 딱 하나의 값만 존재할 수 있고, 선언된 값을 모든 인스턴스에서 공유된다.
    
- 인스턴스 변수
    
    인스턴스 변수는 인스턴스 별로 각자 가지는 별개의 변수이다.
    
- 지역 변수
    
    지역 변수는 메서드나 생성자 블록 내에 위치한 변수이다.
    

### 1.3 메서드

메서드는 클래스 안에 있는 함수이다. Java는 함수가 단독으로 존재하지 못하고 클래스 안에 있어야 해서 메서드라고 많이 불린다.

메서드를 정의할 땐 접근 제어자, 반환 타입, 메서드명, 매개변수 목록, 구현부로 이루어진다.
아래 예시를 보면 이해하기 쉽다.

```java
public              int        sum        (int a, int b)    {  return a + b;  }
// 접근 제어자   반환 타입    메서드명       매개변수 목록          구현부
```

필드에서 클래스 변수와 인스턴스 변수가 나뉘듯이 메서드도 클래스 메서드와 인스턴스 메서드로 나뉜다.
마찬가지로 `static`  키워드를 가지는 메서드를 클래스 메서드, 키워드를 가지지 않는 메서드는 인스턴스 메서드라고 한다.

그래서 클래스 메서드와 클래스 변수 둘 다 인스턴스 선언 없이 사용할 수 있다는 특징을 가진다.
하지만, 인스턴스 선언 없이 사용할 수 있어야 하기 때문에 클래스 메서드는 내부에서 인스턴스 변수를 사용할 수 없다.

### 1.4 메서드 오버로딩

메서드 오버로딩은 같은 이름의 메서드를 매개변수 개수나 타입을 다르게 해서 여러 개 정의하는 걸 말한다.

- **오버로딩 성립 조건**
    - 같은 이름의 메서드이다
    - 매개변수의 개수 or 타입이다

## 2. 생성자


### 2.1 생성자 기본 규칙

생성자는 객체가 생성될 때 인스턴스 변수를 초기화하기 위해 실행되는 특수한 메서드이다.

생성자의 이름은 반드시 클래스의 이름과 같아야 하고, return 타입도 지정할 수 없다.(void도 안 쓴다)
 `new` 로 객체를 만들 때 반드시 호출되며, 혹시라도 생성자를 안 만들면 컴파일러가 기본 생성자를 넣어준다.

### 2.2 this 참조 변수

매개변수명과 인스턴스 변수명이 같을 때 구분용으로 쓴다.

```java
class Car {
    String modelName;

    Car(String modelName) {
        this.modelName = modelName; // 왼쪽 this.modelName은 인스턴스 변수, 오른쪽은 매개변수
    }
}
```

### 2.3 this() 메서드

같은 클래스의 다른 생성자를 호출할 때 쓴다.

```java
class Car {
    Car(String modelName, int year) { ... }

    Car() {
        this("소나타", 2012); // 다른 생성자 호출, 반드시 첫 줄
    }
}
```

### 2.4 생성자 오버로딩

매개변수 다르게 여러 개를 정의할 수 있고 입력값 일부만 줘도 객체 생성 가능하게 유연성을 준다.

```java
class Student {
    Student(int id, String name) { ... }
    Student(String name) { ... }
    Student() { ... }
}
```
